# Contributing

Contributions are welcome.

## Ways to Contribute

You can contribute by:

- Improving explanations
- Correcting technical inaccuracies
- Adding networking examples
- Improving diagrams
- Suggesting documentation improvements
- Fixing broken links

## Guidelines

Please keep contributions:

- Technically accurate
- Clear and easy to understand
- Focused on networking concepts
- Free from unnecessary complexity

## Pull Requests

Before submitting a pull request:

1. Review your changes.
2. Check documentation links.
3. Verify technical claims.
4. Keep changes focused and understandable.

For larger changes, opening an issue first is recommended.

Thank you for helping improve the project.

# Security Policy

## Scope

This repository is an educational resource focused on networking and Quality of Service (QoS).

It does not provide a production network service or process live network traffic.

## Reporting Issues

If you discover a security-related issue in the repository, please report it privately rather than publishing sensitive details in a public issue.

You can contact the maintainer through the GitHub profile:

https://github.com/armoury43

## Responsible Disclosure

Please avoid including credentials, private network information, or other sensitive data in reports.

Security-related reports will be reviewed and addressed as appropriate.
